# mspr - My Switch Ports Repo

## What is this?

I was originally intending for this space to be saved for ports that I personally updated/re-compiled
against the latest libnx libraries to ensure compatibility with FW ≤22.5.0. The mission for this page
has shifted a little bit; I now welcome anyone's contributions, please see the [GBATemp thread]() for
more information on the progress with the latest conversions and
[robzilla10001/SwitchPorts](https://github.com/robzilla10001/SwitchPorts) for a (mostly) up-to-date
list of the available ports for Switch.
